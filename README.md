# clone-tabnews

tabnews.com.br clone for study. check it out!

## requirements

To run this project, you will need the following:

- Node.js >= 24.0.0 (recomendado: 24.16.0 via `.nvmrc`)
- npm >= 8.0.0
- Yarn >= 1.22.22
- Docker
- Docker Compose

## environment variables:

- POSTGRES_HOST
- POSTGRES_PORT
- POSTGRES_USER
- POSTGRES_DB
- POSTGRES_PASSWORD
- POSTGRES_SSLMODE
- DATABASE_URL
